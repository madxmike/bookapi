# 001 HEAD 503 becomes 204

A HEAD request must mirror GET. This mutation makes the read handler answer
204 for HEAD when storage is unavailable, while GET still answers 503. It is
observable on a real net/http server because HEAD would otherwise return the
same status as GET.

Expected failure: `TestHeadMirrorsEveryGetStatus/503` reports
`HEAD status = 204, want 503`.
